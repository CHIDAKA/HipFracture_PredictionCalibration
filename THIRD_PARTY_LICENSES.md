# Third-Party Package Licenses

This file records third-party packages used by this repository and their
license information.

## Why this is needed

- Clarifies redistribution and reuse conditions
- Supports reproducibility requirements for academic publication
- Reduces legal/compliance risk when sharing code and artifacts

## How to maintain

When adding or updating dependencies, add an entry with:

- Package name
- Version
- License
- Source URL
- Notes (if attribution or notice requirements exist)
